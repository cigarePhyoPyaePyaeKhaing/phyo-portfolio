# Phyo Pyae Pyae Khaing · Portfolio

A responsive pink and lavender portfolio built with React, TypeScript, Vite and Tailwind CSS v4. All fonts use local system fallbacks; no external font service or analytics is required.

## Run locally

Install Node.js 22 or newer, then open a terminal in this folder:

```sh
npm install
npm run dev
```

Open the local address printed by Vite (normally http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

The build command checks TypeScript and generates a static production site in `dist/`. Deploy that folder to a static host. This site needs no API keys or backend.

## Edit content

Project descriptions, certificate metadata, contact details, and sections are in `src/main.tsx`. Styling and responsive breakpoints are in `src/styles.css`. Certificate images are in `public/certificates/`.
